LOGO DE CENTAURO
================

Guarda aqui el logo con el nombre  logo.png  (tambien sirve logo.svg,
logo.jpg o logo.webp).

La extension del nombre no importa: el sistema reconoce el formato real
por el contenido del archivo. Si bajas un .webp de la pagina y lo guardas
como logo.png, funciona igual.

Lo unico que importa es que el archivo este completo. Si se bajo a medias,
el sistema NO lo incrusta y pone "CENTAURO" en texto, para no dejar un
hueco en el documento del cliente.

Para saber que esta viendo el sistema:
    docker compose exec api python -c "from app.marca import diagnostico; print(diagnostico())"

EL ACTUAL (20 de septiembre de 2026)
------------------------------------
PNG de 1200 x 269 px, 39 KB, con el fondo transparente. Salio del JPG
grande que mando Salvador: se le recorto el blanco de alrededor, se le
quito el fondo por inundacion desde los bordes --solo el de afuera, para
no agujerear el arco ni la figura, que tambien son blancos-- y se bajo a
1200 px de ancho.

Por que 1200 y no el original de 4080: el logo se incrusta en base64
DENTRO de cada documento y de cada correo, asi que cada byte se paga en
todos. A 1200 px imprime bien y el archivo pesa 39 KB.

Va sobre fondo claro. El texto es azul #1B1546 y sobre oscuro se pierde;
el dia que haga falta uno para fondo oscuro, es otro archivo.
